# Авито-Перехватчик: Двусторонний Серверлесс-мост (YCF + Telegram)

[![Tests](https://img.shields.io/badge/tests-8%20passed-brightgreen.svg)](test/run-mock.js)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Zero Dependencies](https://img.shields.io/badge/dependencies-0%20npm-orange.svg)](package.json)
[![Runtime](https://img.shields.io/badge/runtime-Node.js%2018%2B-green.svg)](index.js)

Автономный двусторонний серверлесс-мост между **Авито (Messenger API)** и **Telegram (Bot API)** для предпринимателей, мастеров и селлеров на Авито.

Позволяет мгновенно отвечать покупателям за <1 секунду, защищать зеленый бейдж **«Отвечает за минуту»** в поиске Авито и вести переписку с клиентами прямо из Telegram через обычный свайп (Reply).

Разработан в лаборатории [Нейро-студии](https://poptech.space).

---

## Ключевые возможности

1. **Мгновенный автоответ покупателям за <1 сек** — гарантирует статус «Отвечает за минуту» в выдаче Авито.
2. **Пуш лида в Telegram** — с названием объявления, именем покупателя, текстом вопроса и кнопкой прямого перехода в диалог на Авито.
3. **Двусторонняя переписка (2-Way Chat)** — продавец отвечает на пуш покупателя **прямо из Telegram через обычный Reply (цитирование)**. Ответ автоматически доставляется покупателю в чат Авито через официальный API.
4. **Умный Fallback** — если продавец ответил обычным текстом без Reply, бот автоматически отправит ответ в последний активный диалог.
5. **Безопасность и защита от циклов**:
   * Встроенная защита от бесконечного цикла сообщений (`author_id === AVITO_USER_ID`);
   * Строгая фильтрация по `TELEGRAM_CHAT_ID` (посторонние пользователи не могут управлять ботом или отправлять сообщения в Авито).
6. **0 ₽/мес абонентской платы за сервер**: работает в пределах бесплатного лимита Yandex Cloud Functions (1 000 000 вызовов в месяц бесплатно). Также доступен запуск в нативном [Telegram Serverless](examples/telegram-serverless/).

## Архитектура и стек

* **Среда выполнения:** Yandex Cloud Functions (Node.js 18+ / 20+) или Telegram Serverless.
* **Внешние зависимости:** 0 npm-пакетов (нативный `fetch` Node.js).
* **Размер архива при деплое:** <12 КБ.
* **Холодный старт:** <150 мс.

## Варианты развертывания

1. **Yandex Cloud Functions (основной вариант)**: подробная пошаговая инструкция приведена ниже.

## Настройка окружения (.env)

Скопируйте шаблон конфигурации:
```bash
cp .env.example .env
```

Заполните переменные в `.env`:

| Переменная | Описание | Где получить |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота | [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_CHAT_ID` | Ваш личный ID в Telegram | [@userinfobot](https://t.me/userinfobot) или [@getmyid_bot](https://t.me/getmyid_bot) |
| `AVITO_CLIENT_ID` | Client ID из кабинета API Авито | [avito.ru/professionals/api](https://www.avito.ru/professionals/api) (права на «Сообщения») |
| `AVITO_CLIENT_SECRET` | Client Secret из кабинета API Авито | [avito.ru/professionals/api](https://www.avito.ru/professionals/api) |
| `AVITO_USER_ID` | Числовой ID вашего профиля на Авито | Кабинет API Авито |
| `AUTO_REPLY_TEXT` | Текст первого автоответа покупателю | Настраивается произвольно |
| `AUTO_REPLY_ENABLED` | Флаг автоответа (`true` / `false`) | По умолчанию `true` |

## Быстрый запуск и сквозное тестирование

### Шаг 1. Локальные юнит-тесты (без внешних сервисов)
```bash
npm test
```
Запускает 8 unit-тестов с полным покрытием логики (парсинг вебхука Авито, защита от петель, извлечение chat_id при Reply, команды Telegram, отсечение посторонних пользователей, CORS OPTIONS, эмуляция mock-сервера Авито, fallback без Reply).

### Шаг 1.1. Живой тест с реальным Telegram-ботом через Эмулятор (БЕЗ API Авито)
Если у вас еще нет доступа к официальному кабинету Авито API или вы хотите протестировать связку прямо сейчас:
1. Укажите в `.env` только токен бота и ваш Telegram ID:
   ```dotenv
   TELEGRAM_BOT_TOKEN=7123456789:AAH_xxx
   TELEGRAM_CHAT_ID=123456789
   ```
2. Запустите интерактивный эмулятор:
   ```bash
   npm run emulator
   ```
3. Эмулятор поднимет локальный Mock-сервер Авито (порт 4040), подключит Telegram Poller и откроет меню.
4. Выберите вопрос покупателя в консоли:
   * Эмулятор мгновенно отдаст автоответ в mock-чат;
   * На ваш телефон в Telegram поступит реальный пуш с карточкой лида;
   * Ответьте на пуш в телефоне через **Reply** $\rightarrow$ ваш ответ отобразится в консоли покупателю!

---

### Шаг 2. Деплой в Yandex Cloud Functions (боевой запуск)
```bash
npm run deploy
# или ./deploy.sh
```
Скрипт автоматически:
1. Упакует код в zip-архив (исключая локальные `.env` файлы);
2. Создаст функцию `avito-bridge` в YC (если еще не создана);
3. Загрузит переменные из `.env` в функцию;
4. Сделает функцию публичной и выведет готовый URL вебхука:
   `https://functions.yandexcloud.net/<FUNCTION_ID>`

### Шаг 3. Регистрация Webhook в Telegram
```bash
npm run register:tg
```
Связывает вашего бота Telegram с URL развернутой функции. После этого проверьте бота: отправьте ему команду `/start` или `/status`.

### Шаг 4. Регистрация Webhook в Авито
```bash
npm run register:avito
```
Регистрирует URL функции в официальном Avito Messenger API (`POST /messenger/v3/webhook`).

### Шаг 5. Сквозной тест на реальном объявлении
1. Откройте объявление на Авито с тестового аккаунта / телефона и напишите сообщение.
2. Убедитесь, что в течение 1 секунды пришел автоответ.
3. В личный Telegram поступит уведомление с деталями лида.
4. Ответьте на сообщение в Telegram (сделайте свайп влево / Reply).
5. Проверьте диалог на Авито: ответ мгновенно отобразится покупателю!
