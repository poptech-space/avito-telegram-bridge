# Telegram Serverless: статус переноса

Native Telegram не является поддерживаемым runtime этого репозитория.
Рабочий путь: YCF Node.js 22 + YDB, Telegram Bot API, отдельный приватный worker.
Матрица runtime закреплена в [ops/runtime.json](../../ops/runtime.json).

Прежний `endpoints/avito.js` удалён: он использовал неподтверждённые импорты SDK,
схему SQLite, URL и команды CLI, не проверял источник webhook и не реализовывал
двустороннюю доставку с dedup. Разворачивать его как готовую интеграцию нельзя.

Для отдельного переноса нужно проверить по [официальной документации](https://core.telegram.org/bots/serverless):

- возможность приёма внешнего webhook Авито и проверки его capability;
- актуальные API SQLite, атомарность dedup и заданий доставки;
- проверенный контекст владельца и безопасную привязку Reply к диалогу;
- восстановление pending, ограничения исходящего HTTP и секретов;
- установку и версии CLI, миграции и реальную приёмку на отдельном боте.

Наличие платформы и примеров у других проектов не подтверждает совместимость
этого моста. Не публиковать вымышленные замеры или команды запуска.
